# media — תמונות וסרטונים של הפרויקטים

תיקייה אחת לכל פרויקט. השם שלה הוא הערך של `folder` בפרויקט, בקובץ
`js/content.js`.

```
media/
  01-apartment-renovation/
    before.jpg      ← המצב לפני העבודה
    after.jpg       ← המצב אחרי (או after.mp4 לסרטון)
  02-housing-unit/
    ...
```

## הכללים

- **השמות קבועים:** `before` ו-`after`. הסיומת יכולה להיות
  `jpg`, `jpeg`, `png`, `webp` (תמונה) או `mp4`, `webm` (וידאו).
- **האתר מוצא את הקבצים לבד** — אין צורך לכתוב את השמות בשום מקום.
- אם יש באותו צד גם וידאו וגם תמונה (`after.mp4` + `after.jpg`) — מוצג
  הווידאו, והתמונה מוצגת עד שהוא מתחיל להתנגן.
- הקבצים `before.svg` / `after.svg` הם **תמונות זמניות**. קובץ אמיתי גובר
  עליהם אוטומטית, ואחרי שמוסיפים אותו אפשר למחוק את ה-SVG.
- אותיות קטנות בלבד בשמות הקבצים (`before.jpg`, לא `Before.JPG`) — השרת
  של GitHub Pages מבחין בין אותיות גדולות לקטנות.

## פרויקט חדש

1. צרו תיקייה חדשה, למשל `media/07-kitchen-renovation/`.
2. שימו בה `before.jpg` ו-`after.jpg`.
3. הוסיפו פרויקט ב-`js/content.js`:
   ```js
   { folder: '07-kitchen-renovation', title: 'שיפוץ מטבח', place: 'נתניה',
     category: 'בנייה ושיפוצים', text: 'תיאור קצר' }
   ```

## טיפים לצילום

- **לצלם לפני ואחרי מאותה נקודה ובאותה זווית** — כך הגרירה ביניהם עובדת.
- לצלם לרוחב. המסגרת היא ביחס 4:3, ותמונה בפרופורציה אחרת נחתכת למילוי.
- תמונה: עד 1600 פיקסלים רוחב ובערך 300KB — מספיק חד ונטען מהר.
- וידאו: קצר (5–15 שניות), MP4, בלי קול — הוא מתנגן אוטומטית ובלולאה.
