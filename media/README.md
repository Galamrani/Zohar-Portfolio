# media — תמונות וסרטונים של הפרויקטים

תיקייה אחת לכל פרויקט. השם שלה הוא הערך של `folder` בפרויקט, בקובץ
`js/content.js`. בתוכה שמים כמה תמונות וסרטונים שרוצים — הם מוצגים
בגלריה שמחליקים בה הצידה.

```
media/
  01-apartment-renovation/
    1.jpg
    2.jpg
    3.mp4
    4.jpg
  02-housing-unit/
    ...
```

## הכללים

- **השמות הם מספרים**, לפי סדר ההצגה: `1`, `2`, `3`... הסיומת יכולה
  להיות `jpg`, `jpeg`, `png`, `webp` (תמונה) או `mp4`, `webm`, `mov` (וידאו).
- **המספור רציף** — האתר מפסיק לחפש במספר הראשון שחסר. אם יש `1.jpg`,
  `2.jpg` ו-`4.jpg`, התמונה `4.jpg` לא תוצג.
- **האתר מוצא את הקבצים לבד** — אין צורך לכתוב את השמות בשום מקום.
- אם יש באותו מספר גם וידאו וגם תמונה (`3.mp4` + `3.jpg`) — מוצג
  הווידאו, והתמונה מוצגת עד שהוא מתחיל להתנגן.
- הקבצים `1.svg` / `2.svg` הם **תמונות זמניות**. ברגע שיש בתיקייה קובץ
  אמיתי אחד לפחות הם מוסתרים, ואפשר למחוק אותם.
- אותיות קטנות בלבד בסיומות (`1.jpg`, לא `1.JPG`) — השרת של GitHub
  Pages מבחין בין אותיות גדולות לקטנות.

### שמות חופשיים

לא רוצים למספר? אפשר לכתוב את שמות הקבצים ידנית בשדה `media` של
הפרויקט, והם יוצגו בדיוק בסדר הזה:

```js
{ folder: '07-kitchen-renovation', title: 'שיפוץ מטבח', place: 'נתניה',
  category: 'בנייה ושיפוצים', text: 'תיאור קצר',
  media: ['before.jpg', 'work.mp4', 'after.jpg'] }
```

## פרויקט חדש

1. צרו תיקייה חדשה, למשל `media/07-kitchen-renovation/`.
2. שימו בה `1.jpg`, `2.jpg` וכן הלאה.
3. הוסיפו פרויקט ב-`js/content.js`:
   ```js
   { folder: '07-kitchen-renovation', title: 'שיפוץ מטבח', place: 'נתניה',
     category: 'בנייה ושיפוצים', text: 'תיאור קצר' }
   ```

## טיפים לצילום

- **הקובץ הראשון (`1`) הוא התמונה שרואים בכרטיס** — כדאי שיהיה החזק ביותר.
- לצלם לרוחב. המסגרת היא ביחס 4:3, ותמונה בפרופורציה אחרת נחתכת למילוי.
- תמונה: עד 1600 פיקסלים רוחב ובערך 300KB — מספיק חד ונטען מהר.
- וידאו: קצר (5–20 שניות), MP4, בלי קול — הוא מתנגן אוטומטית ובלולאה
  כשמגיעים אליו בגלריה.
